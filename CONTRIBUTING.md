# Contributing

1. Sign every commit off under the Developer Certificate of Origin (`git commit -s`, <https://developercertificate.org>).
2. Contribute only your own work. Nothing copied from another codebase, product or organisation; see `docs/provenance.md`.
3. One pull request per change, referencing the issue it closes.
4. Every change is judged against `REVIEW.md`; read it before opening the pull request.
