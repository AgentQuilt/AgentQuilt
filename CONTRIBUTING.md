# Contributing

1. Sign every commit in your pull request off under the Developer Certificate of Origin (`git commit -s`, <https://developercertificate.org>).
2. Contribute only work that is yours to give. Nothing proprietary or confidential from any codebase, product or organisation; licensed open-source reuse follows `docs/provenance.md`.
3. One pull request per change, referencing the issue it closes.
4. Every change is judged against `REVIEW.md`; read it before opening the pull request.
